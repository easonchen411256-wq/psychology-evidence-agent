# 普度众大学生｜产品说明

## 产品定位

面向心理学研究与论文写作场景的证据整理 Agent。它将“检索—初筛—合法全文定位—证据卡—证据矩阵—人工审查—综述初稿”串成可追溯工作流，而不是通用论文推荐或自动代写工具。

## 目标用户

需要整理心理学论文证据的本科高年级学生、研究生和研究者。当前默认检索配置服务于“老年人跌倒恐惧、心理干预、步态与心率/HRV 监测”课题。

## 核心能力

1. 从 OpenAlex 获取公开元数据、按 DOI/OpenAlex ID/标题去重，并保留检索记录。
2. 依据题名、摘要和元数据初筛候选论文，输出优先阅读清单、人工核对提示与未筛候选。
3. 通过 OpenAlex、可选 Unpaywall、Europe PMC/PMC 定位合法开放版本；未获得全文时生成授权访问的人工队列。
4. 从用户提供或已合法获得的 PDF、Markdown 或文本中提取结构化证据卡。
5. 汇总多篇已校验证据卡为 JSON、CSV、Markdown 比较矩阵、人工核对清单和 Word 文献审查报告。
6. 只依据证据卡中已有 finding 与 evidence location 生成谨慎的综述初稿。

## 非目标

- 不替代人工全文阅读、研究判断或系统综述注册流程。
- 不根据未提供材料补写研究结果、参考文献或 DOI。
- 不将标题/摘要初筛结果视为全文级证据。
- 不将相关、预测、因果和干预效果混为一谈。
- 不绕过付费墙、机构登录、验证码或版权限制。

## 成功标准

- 证据卡的主要结论可追溯到输入材料与原文位置。
- 综述初稿的事实性主张能回溯到具体证据卡、finding 和 evidence location。
- 不确定内容被标记为“未报告”“无法判断”或“需人工核对”。
- 仅通过 JSON Schema 与本地推论边界校验的证据卡才被写入结果目录。
