# 工作流程

1. 在 `configs/` 中定义研究主题、研究问题与多组检索查询。
2. 从 OpenAlex 获取公开元数据，按 DOI、OpenAlex ID 或标准化标题去重，保存候选集和检索报告。
3. Codex CLI 只根据题名、摘要和元数据初筛候选论文，输出相关性、候选证据层级和人工核对提示；未筛候选必须单独保存。
4. 从初筛结果生成优先阅读清单；该清单仅决定阅读顺序，不代表全文级证据结论。
5. 对优先论文检查 OpenAlex、可选 Unpaywall、Europe PMC/PMC 的合法开放版本；明确开放 PDF 才可下载，其他条目进入人工授权获取队列。
6. 接收用户提供或已合法获得的 PDF、Markdown 或文本材料；本地 PDF 提取保留页码标记，扫描版/加密版/图表复杂材料标记人工核对。
7. 本地程序以 read-only 模式启动 Codex CLI，并将论文材料作为不可信证据来源传入。
8. Codex CLI 按提示词和 JSON Schema 生成候选证据卡，提取研究设计、样本、变量、发现、局限和人工核对项。
9. 本地校验器执行 JSON Schema 与研究设计—推论边界规则；仅通过校验的证据卡才写入结果文件。
10. 批量模式可顺序处理多篇已授权材料，并保留每篇独立证据卡。
11. 汇总多篇已校验证据卡为 JSON、CSV、Markdown 比较矩阵和人工核对清单；直接、相邻、背景角色仍由人工阅读全文确认。
12. 综述初稿只使用证据卡中已有的 finding、evidence location、研究设计和局限；无法绑定来源的事实性主张不得写入。
