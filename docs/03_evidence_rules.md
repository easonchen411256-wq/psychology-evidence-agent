# 证据规则

## 推论强度

- 横断面研究：通常只支持变量间关联。
- 纵向观察研究：可支持时间顺序或预测关联，不自动支持因果。
- 随机对照试验：在其样本、干预和测量范围内，可支持较强的干预效应推论。
- 系统综述或元分析：需要检查纳入研究质量与异质性。

## 输出纪律

- 未在材料中报告的信息，写“未报告”。
- 无法由材料判断的信息，写“无法判断”。
- 需要回看原文图表、附录或方法细节时，写“需人工核对”。

## 结构校验

- 每张证据卡必须同时通过 `src/psychology_evidence_agent/resources/schemas/evidence_card.schema.json` 的 JSON Schema 校验和本地推论边界校验，才会被写入 `data/processed/`。
- Schema 校验会检查必填字段、字段类型、枚举值、嵌套对象结构及未知字段；因此不能只保留顶层字段而省略其内部必填信息。
- 本地推论边界校验是 Schema 之外的补充。例如，横断面研究不能把“相关”写成因果或干预效果；材料不完整时必须保留人工核对项。
- 结构校验通过不等于研究结论已被证实，仍须根据原文、页码与人工核对项判断证据是否适合写入论文。
