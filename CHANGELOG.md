# Changelog

All notable changes to this project are recorded here. The project is still in
the 0.x phase, so interfaces may evolve before the first stable release.

## [Unreleased]

- Added repository-facing security, environment and offline demonstration
  documentation.
- Added explicit original-author ownership, authorship and citation metadata.
- Added release and reproducibility guidance for local demonstrations.
- Updated GitHub Actions to the current major versions used by the workflow.

## [0.1.0] - 2026-09-10

- Established the standard Python package and `src` layout.
- Added the unified `pea` CLI and the local browser research workspace.
- Added bounded Agent planning, Human Gate handling, artifact persistence and
  restart-aware run control.
- Added mocked CI coverage for paper APIs and model calls, schema checks, wheel
  build and wheel smoke testing.
